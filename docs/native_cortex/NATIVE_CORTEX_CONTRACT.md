# Mega PRIME — Native Cortex

Status:

    EXPERIMENTAL NATIVE LANGUAGE CORTEX

Purpose:

    Give PRIME learned, distributed, recurrent linguistic competence while
    preserving verifier sovereignty, provenance, observability and
    interpretability.

---

# Fundamental separation

The cortex may:

    predict;
    associate;
    remember volatile context;
    generate language;
    route computation;
    form distributed features;
    propose semantic interpretations;
    predict verifier outcomes.

The cortex may NOT:

    mutate canonical PRIME knowledge;
    authorize a proposition;
    rewrite provenance;
    delete receipts;
    declare its own output true.

Therefore:

    neural proposal != epistemic authority

---

# Computational thesis

The cortex is not a conventional Transformer.

Its initial architecture combines:

    byte-level language modelling;

    recurrent matrix-valued delta memory;

    ternary learned projections;

    sparse mixture-of-experts computation;

    residual computation;

    streaming constant-size recurrent state.

The purpose is to investigate language capability per unit compute rather than
maximum parameter count.

---

# Memory hierarchy

Level 1:

    volatile recurrent cortex state

Level 2:

    future plastic / fast neural memory

Level 3:

    PRIME canonical memory

Important durable information should migrate upward rather than requiring
unbounded neural context.

---

# Observability

Observability is native to the forward architecture.

Each observable cognitive step may emit TSObs data containing:

    token identity;

    model identity;

    recurrent-state norm;

    erase strength;

    write strength;

    selected experts;

    expert routing confidence;

    verifier-head prediction;

    output alternatives.

Observability levels:

    O0
        hashes and health metrics

    O1
        routes, reads, writes and proposals

    O2
        compressed latent summaries

    O3
        selected forensic activation capture

Normal execution targets O1.

---

# Interpretability

A neural feature may occupy one of three semantic states:

    UNKNOWN

    CHARACTERISED

    CRYSTALLISED

UNKNOWN features are explicitly allowed.

The system must never fabricate a semantic explanation merely because a
feature is useful.

A feature may become CHARACTERISED through repeated activation analysis and
causal intervention.

A sufficiently stable useful feature may produce a PRIME construction
proposal.

Only verifier-backed constructions may become CRYSTALLISED canonical concepts.

---

# Attribution

Every consequential state mutation must identify its actor.

Examples:

    optimizer update;
    human modification;
    cortex proposal;
    verifier commit;
    memory repair;
    representation retirement.

No component may rewrite its own historical telemetry.

---

# Language

The cortex's language model is competence, not canonical knowledge.

Its outputs may be fluent and wrong.

The PRIME verifier / memory architecture remains responsible for epistemic
status.

---

# Initial scientific boundary

The initial Native Cortex prototype is architecture development.

Language fluency from a tiny training corpus is not a scientific capability
claim.

The immediate target is a functional low-compute trainable language kernel
with native observability and streaming recurrent state.
