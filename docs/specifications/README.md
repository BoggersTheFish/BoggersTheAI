# Thinking System Specifications

This directory contains formal specifications governing Thinking System representations, schemas, transactions, and receipt structures:

---

## Specification Documents

* `TSIR Specification`: Typed Intermediate Representation format (`TSIR-0.1`).
* `Receipt Schema Specification`: Content-addressable receipt format (`TSReceipt-0.1`).
* `Authority Boundary Specification`: Verifier obligation enforcement rules.
* `BOGVM Specification`: Bytecode instruction set and execution driver specifications.
