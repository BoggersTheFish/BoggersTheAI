# Thinking System Project History

Thinking System originated as a verifier-first research programme to replace black-box, ungrounded neural reasoning with structured residual accounting and content-addressable receipts.

---

## Lineage Milestones

1. **Early Prototypes (2026-Q1/Q2):**
   * `TensionLM`: Early sigmoid-tension language model experiments.
   * `TS-Reasoner-v0`: Initial TS-Reasoner v30.0.0 local agent OS prototype.

2. **Substrate & Kernel Expansion (2026-Q2):**
   * `TS-Core` & `TS-OS`: BOGVM bedrock runtime, process driver, and vector memory specifications.
   * `TensionForge`: OpenCL GPU compute substrate for legacy hardware.
   * `TS-LAB`: Phase 0 constitutional boundaries and schema specifications.
   * `TS-Benchmarks`: Falsification and topology-aware benchmark harness.
   * `ts-chat-language`: Thinking System Language Compiler (TSLC) and Deterministic Dialogue Substrate.

3. **Canonical Monorepo Consolidation (2026-Q3):**
   * Consolidated `BoggersTheAI` into `thinking-system` monorepo.
   * Established canonical `TSKernel` authority boundary, `ts` CLI, and unified package hierarchy.
