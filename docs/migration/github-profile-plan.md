# GitHub Profile Optimization & Pinning Plan

This document outlines the recommended GitHub profile structure for `@BoggersTheFish` to present Thinking System as a serious, verifier-first research and engineering programme.

---

## 1. Recommended Pinned Repositories (Top 6)

1. **`thinking-system`** (Primary Flagship Monorepo)
   * **Description:** Verifier-first research architecture for constructing, measuring, localising and minimally revising structured reasoning systems.
   * **Role:** Flagship research monorepo & canonical implementation.

2. **`bogbin`** (Verified Storage Substrate)
   * **Description:** Verified storage and portable compute substrate for BogOS HyperGenesis.
   * **Role:** Standalone verified-computing foundation for BOGVM binary containers.

3. **`boggersthefish-site`** (Public Research Interface)
   * **Description:** Public web portal for Thinking System proof routes, benchmark bounds, and interactive evidence visualization.
   * **Role:** Official web presence and evidence demonstration.

4. **`ts-spear`** (Applied Anti-Cheat Intelligence Engine)
   * **Description:** Thinking System anti-cheat intelligence engine for Paper Minecraft — state-driven confidence graphs & evidence receipts.
   * **Role:** Applied real-world engineering project demonstrating TS verifier architecture in production Minecraft servers.

5. **`LumaGuilds`** / **`enthusia-network`** (Community & Ecosystem Project)
   * **Description:** Minecraft Paper plugin ecosystem & guild management framework.
   * **Role:** Polished community/applied software project.

6. **`TS-Benchmarks`** (Audit-First Benchmark Harness)
   * **Description:** Audit-first benchmark harness for the Thinking System ecosystem — topology-aware relaxation policy evaluation.
   * **Role:** Falsification dataset & audit harness.
