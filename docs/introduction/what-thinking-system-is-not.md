# What Thinking System Is Not

To prevent misunderstanding, Thinking System explicitly defines what it is **not**:

---

## What Thinking System Is NOT:

1. **NOT a Language-Model Prompt Wrapper:**
   Thinking System does not rely on LLMs for proof authority or state commitment. LLMs serve strictly as candidate proposal generators whose outputs must pass verifier gates.

2. **NOT a Confidence-Based Agent:**
   High LLM probability or logit confidence does **NOT** constitute proof authority. Confidence scores cannot override missing verifier receipts.

3. **NOT an Unbounded Self-Improving Superintelligence:**
   Thinking System does not make unverified claims of autonomous general intelligence. Its implemented scope is strictly verifier-bounded.

4. **NOT a Proprietary API Dependent System:**
   The core TS kernel, BOGVM verifiers, graph dynamics, and receipt replay operate **100% offline** without requiring GPUs, proprietary APIs, or external network access.

5. **NOT an Arbitrary Heuristic Script Collection:**
   All components follow a unified authority model governed by residual accounting and formal verifier obligations.
