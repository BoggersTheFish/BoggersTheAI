# What is Thinking System?

**Thinking System** is a verifier-first research architecture for constructing, measuring, localising, and minimally revising structured reasoning systems under explicit residual or tension accounting.

---

## Governing Pattern

Thinking System operates under the strict governing pattern:

$$\text{representation} \rightarrow \text{lawful quotient} \rightarrow \text{relative residual} \rightarrow \text{sufficient observer family} \rightarrow \text{localised obstruction} \rightarrow \text{minimal typed revision} \rightarrow \text{sealed adversarial evaluation}$$

---

## Core Operational Principles

1. **Verifier-First Transaction Authority:**
   No state change or claim is accepted into canonical storage unless authorized by deterministic, typed verifier obligations.

2. **Residual & Tension Accounting:**
   Tension is not discarded as error noise; it is explicitly measured across activation, contradiction, provenance, and verification dimensions.

3. **Content-Addressable Receipts:**
   Every transaction produces an immutable, SHA-256 hashed execution receipt that allows exact deterministic replay and auditability.

4. **Representation Branching:**
   When faced with contradictory authoritative evidence, the kernel branches representation entities rather than inflating arbitrary confidence scalars.
