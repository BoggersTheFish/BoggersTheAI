# PRIME M22 — Developmental Laboratory

Status:

    ARCHITECTURE + DEVELOPMENT CONTRACT

Parent:

    PRIME M21 Persistent Adaptive Cognition

Purpose:

    Test whether verified experience accumulated across worlds improves the
    efficiency with which PRIME learns later worlds.

This is NOT yet a held-out scientific evaluation.

---

# Core developmental hypothesis

For a sequence of related but non-identical worlds:

    prior verified experience
        ->
    reusable semantic memory
        ->
    schema discovery
        ->
    higher-priority proposal search
        ->
    reduced future representation-discovery latency

The central developmental quantity is:

    transfer gain =
        cold discovery event
        -
        persistent discovery event

Positive values mean accumulated cognition accelerated learning.

---

# Comparison

COLD PRIME

    Starts each chapter without cross-world semantic, episodic, schema or
    proposal-routing memory.

PERSISTENT PRIME

    Retains M21 semantic memory, episodic memory, proposal-field state and
    schema knowledge across chapters.

Both agents receive identical observation streams and identical action
randomness for the same chapter.

---

# Authority invariant

Persistent memory may alter candidate search.

Memory does NOT authorize knowledge.

Schema instantiation does NOT authorize knowledge.

Proposal ranking does NOT authorize knowledge.

Transferred constructions must still pass the M20 verifier in the new world.

---

# Developmental curriculum

The curriculum contains:

    first encounters;
    exact recurrence;
    shifted relational families;
    higher-order relations;
    distractor / CURRENT worlds.

Representative families include:

    LAG
    XOR
    EQ
    AND
    OR
    three-way XOR
    three-way AND
    three-way OR

Shifted families allow schema formation such as:

    XOR(LAG(1), LAG(4))
    XOR(LAG(2), LAG(5))
        ->
    proposed schema:
        XOR(LAG(k), LAG(k+3))

The schema may generate future candidate constructions.

Generated candidates remain proposals.

---

# Candidate-field compression

Cold search uses the full M20 candidate field:

    maximum candidates = 256

When persistent memory or verified schema knowledge provides useful prior
structure, Persistent PRIME may instantiate a smaller prioritized field:

    maximum candidates = 64

This is an explicit architectural mechanism:

    prior verified experience
        ->
    narrower hypothesis search
        ->
    reduced multiplicity cost
        ->
    potentially earlier authorization

A wrong prior may therefore hurt performance.

This is intentional.

Transfer must earn its advantage.

---

# Statistical boundary

M22 initial development is architectural evidence only.

The current M20 per-run global alpha guarantee applies within one chapter.

It is NOT yet claimed to provide one lifetime alpha budget over an unbounded
developmental sequence.

Before any M22 held-out scientific claim, a lifetime sequential-verification
budget must be frozen.

No held-out developmental curriculum is defined in this contract.

# Claim boundary

Development results may show:

    cross-world reuse;
    schema-guided proposal generation;
    developmental acceleration;
    failure or negative transfer.

They do not establish:

    AGI;
    universal meta-learning;
    human-like development;
    general causal discovery;
    universal transfer.
