The failure is not inability to discover or use causal mechanisms.

Both systems identify mechanisms and solve every world.

The failure is epistemic-control strategy.

M24 v0.1 treats remembered programs as an ordered sequence of candidate
theories.

A high-ranked wrong remembered theory may therefore consume targeted
experiments before a lower-ranked correct theory is considered.

Even an exact remembered program does not necessarily reduce intervention
count.

    XOR(A,B) repeat

The correct theory existed in memory but memory was not used as a global
hypothesis distribution.

The architecture therefore confuses:

    prioritized theory testing

with:

    globally optimized experiment selection.

M25 must replace sequential prior testing with a universal weighted causal
hypothesis ecology.

Every frozen causal program remains possible until contradicted.

Prior verified experience changes proposal mass, not authority.

Each intervention must be selected against the entire surviving hypothesis
population.

Spatial / primitive action cost must enter the study objective.
