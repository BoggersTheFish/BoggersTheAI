# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.5.x-alpha` (Thinking System monorepo migration line) | :white_check_mark: (best-effort research software) |
| Pre-alpha / ad-hoc local trees without package version | Best-effort only |

There is **no** 1.0.x release. Do not treat this project as production-supported software.

If you discover a security vulnerability or verifier bypass vulnerability:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately to: `benmichalek06@gmail.com`
3. Include details on reproduction steps, receipt hashes, and affected components.
